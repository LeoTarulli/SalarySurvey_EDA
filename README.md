# Salary Survey - Exploratory Data Analaysis

## Overview
The main focus in this project is to analyze the different salaries around the world in the main countries, such as United States, Australia, United Kingdom, China, etc. The main scope is to understand which are the key parameter that affect the salary earned per employee, as these could be sex, race, age, and so on.

## Technologies
- **Python**: Data management and visualization using Pandas, NumPy, Matplotlib and Seaborn.
- **Github**: Version control and documentation.

## Project breakdown:
1) Importing libraries: Pandas, NumPy, Matplotlib and Seaborn.
2) Importing the data - CSV file
3) Executing Data cleaning: Checking shape, replacing values, removing unnecessary columns and rows that could affect the analysis, removing outliers, dropping null values, etc.
4) Setting and Answering questions: In this section i set main question which i answered using plots.
5) Machine learning preparation: Transforming categorical data into numerical (encoding)
